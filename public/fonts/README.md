# Screen text font

- **Font**: Kenney Pixel (`Fonts/Kenney Pixel.ttf`, renamed `KenneyPixel.ttf`), from the Kenney Fonts pack by Kenney
- **Source**: https://kenney.nl/assets/kenney-fonts
- **Licence**: CC0 1.0, https://creativecommons.org/publicdomain/zero/1.0/ (the pack's `License.txt`, copied here unchanged as `LICENSE.txt`)
- **Downloaded**: 2026-10-29

One font pixel is 1/16 em (glyph outlines sit on a 64-unit grid, 1024 units per em), so `GUI.skin.label.fontSize` rounds to a multiple of 16.
